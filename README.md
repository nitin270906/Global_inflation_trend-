📊 Global Inflation Analysis (Post-COVID)
🚀 Overview

This project analyzes global inflation trends after the COVID-19 pandemic using Python, Exploratory Data Analysis (EDA), and Machine Learning.

The goal is to understand how inflation behaved across countries, identify key influencing factors, and build a predictive model.

🎯 Objectives
Analyze the distribution and variability of global inflation rates
Study inflation trends during post-COVID recovery
Identify relationships between inflation and economic indicators
Analyze the impact of oil prices on inflation
Compare inflation across countries
Build a machine learning model for prediction
